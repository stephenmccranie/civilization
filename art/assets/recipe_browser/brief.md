# Recipe browser

Replace the shared machine recipe drawer's large text buttons with compact icon-and-name rows. Keep the approved tan enamel, iron bevels and brass rivets; source reference is the implemented Smithy screenshot and original coal-machine concept. No machine slots, recipes or processing rules change at this stage.

One direction: compact category tabs (all/tools/weapons/armor/components), contextual material chips (all/iron/gold/diamond/netherite), a searchable scrollable single-column list and one highlighted selection. Filters only narrow the catalog; clicking a recipe selects it and shows ingredient ghosts in the existing machine slots. Rows show names; hover supplies details. Materials are recipe metadata, not inferred solely from output names. Upgrade recipes remain distinguishable from new equipment; Repair and Automatic remain compact explicit actions. Do not hide missing-material recipes or suggest that clicking crafts for free. Omit irrelevant filter rows on simple machines.

Mockup state: Smithy, Tools + Iron, six recipe rows (pickaxe, axe, shovel, hoe, saw, shears), Iron Pickaxe selected. Inputs: 3 iron ingots, 1 leather, 2 sticks, one unused slot; one pickaxe output. Two coal slots and the fire window remain. Category labels appear through tooltips/breadcrumbs, not large text buttons. Implementation uses real item sprites, 18-GUI-pixel rows and existing cabinet art. Fidelity targets: category column outside drawer, material chips above rows, muted breadcrumb, brass left marker/tinted selected row, separate bottom Automatic/Repair icons. Search and native Tab focus remain available; mouse wheel and Page Up/Down navigate the list.
