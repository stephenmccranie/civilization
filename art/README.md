# Art and visual evidence

- [Texture pipeline](textures/README.md): high-resolution masters, consistent block families, native 32×32 export and provenance. Manifests own the active source/output mapping.
- [Concept art and prompts](../concept_art/prompts.md): creative direction; [the great transmission](../concept_art/06_the_great_transmission.png) is the latest sky/tower treatment. These images do not establish implemented mechanics.
- [Machine UI alternatives](../concept_art/prompts.md#machine-ui-alternatives--2026-09-12): three unapproved cabinet, instrument-panel and recipe-ledger mockups for the shared interface discussion; not runtime textures.
- `construction/`: selected in-game evidence, including [modular assemblies](construction/modular-cells.png) and [correct material synchronization](construction/material-sync-fixed.png). The [reproduced renderer bug](construction/material-sync-bug.png) is historical evidence.

New generation follows the texture pipeline and the available image-generation skill. Preserve sources, exact prompts and receipts. Runtime textures belong in mod resources; raw masters and review sheets stay here. Do not generate block faces independently or copy Faithful assets into the mod.

Temporary screenshots stay in ignored `civilization-mod/runs/visual/screenshots`; retain only useful reviewed evidence here. Reuse descriptive names for current comparisons and label superseded experiments as history.
